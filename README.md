# Vision Admin (back-office)

React back-office for the Vision sports balls shop. Module 1: admin authentication.

## Setup
```bash
npm install
copy .env.example .env
npm run dev
```
Requires the API ([ballons-tunisie-api](https://github.com/Boussiga/ballons-tunisie-api)) running on http://localhost:3000. The Vite dev server proxies `/api` to it.
